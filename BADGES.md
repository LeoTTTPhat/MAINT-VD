# Artifact Badge Plan

This project is prepared for an artifact-review workflow.

## Target Badges

- Available: release normalized temporal exports, split manifests, metrics, and scripts under a DOI.
- Functional: provide a containerized environment and smoke-test commands that rebuild the main tables from the released artifacts.
- Reusable: document dataset provenance, licenses, SHA-256 checksums, and scripts that produce each artifact.
